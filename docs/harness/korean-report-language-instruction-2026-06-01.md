# 한국어 보고서 작성 지침 추가

작성일: 2026-06-01

## 목표

향후 harness 보고서, 검증 요약, 구현 보고서, 계획서, 변경 기록을 기본적으로 한국어로 작성하도록 저장소 운영 지침에 명시한다.

## 변경한 파일

- `AGENTS.md`
- `docs/harness/feature-documentation-guide.md`
- `docs/harness/korean-report-language-instruction-2026-06-01.md`

## 동작 변경

- 사용자에게 보고할 때 harness 보고서, 검증 요약, 구현 보고서, 계획서, 변경 기록은 사용자가 다른 언어를 명시하지 않는 한 한국어로 작성한다.
- 변경 기록도 기본적으로 한국어로 작성한다.
- 코드 식별자, 파일 경로, 명령어, API 경로, 오류 문자열은 원문을 유지한다.

## 검증

- 문서 변경만 수행했으므로 테스트는 실행하지 않았다.

## 후속 위험

- 기존 문서 중 영어로 작성된 기록은 그대로 남아 있다. 새 문서와 향후 갱신분부터 이 지침을 적용한다.
