# 1. 시스템 흐름도 (Flow Chart)

서비스명: **AI Invest** / 기준: 현재 구현 코드(`backend/`, `frontend/`)

## 1.1 전체 시스템 구성도

```mermaid
flowchart TB
    subgraph Client["사용자 / 브라우저"]
        U["사용자"]
    end

    subgraph FE["Frontend (React + Vite, Vercel)"]
        APP["App.jsx 라우팅"]
        PAGES["pages/* 화면"]
        STORE["store/* (Zustand)<br/>auth · subscription · favorite · chat"]
        API["utils/apiClient.js (axios)"]
    end

    subgraph BE["Backend (FastAPI, Render)"]
        ROUTER["api/* 라우터<br/>auth·billing·community·chat·favorites·notifications·profile"]

        SVC["services/*<br/>market·macro·ai·chat·notification·subscription·payment"]
        SCHED["APScheduler<br/>가격·뉴스·리포트·알림 배치"]
        GRAPH["LangGraph 파이프라인<br/>graph/nodes.py"]

    end

    subgraph EXT["외부 연동"]

    end

    DB[("PostgreSQL")]

    U --> APP --> PAGES --> STORE --> API
    API -->|REST / JWT Bearer| ROUTER
    API -->|REST / JWT Bearer| MARKET
    ROUTER --> SVC
    MARKET --> SVC
    SVC --> DB
    SVC --> CACHE
    SCHED --> SVC
    SVC --> GRAPH --> LLM
    ROUTER -.인증.-> GOOGLE
    SCHED --> DATA
    SVC --> DATA
    ROUTER -.결제.-> TOSS
    SCHED --> NOTIFY
```

## 1.2 인증 흐름 (Google 로그인 단일 흐름)

```mermaid
flowchart LR
    A["로그인 화면<br/>Login.jsx"] -->|Google ID Token| B["POST /api/auth/google"]
    B --> C{"google-auth로<br/>ID Token 검증"}
    C -->|성공| D["User 조회/생성<br/>(google_sub 기준)"]
    D --> E["JWT 액세스 토큰 발급"]
    E --> F["authStore + localStorage 저장"]
    F --> G["이후 요청 Authorization: Bearer 토큰"]
    C -->|실패| H["401 인증 오류"]
```

## 1.3 시장 데이터 조회 흐름 (캐시 우선)

```mermaid
flowchart LR
    S["APScheduler"] -->|주기 실행| T["update_prices_task /<br/>update_news_task"]
    T --> X["외부 시장 API 수집·정규화"]
    X --> CC["메모리 캐시 갱신"]
    U["사용자 요청<br/>GET /api/market/prices"] --> R["라우트"]

```

> 핵심 원칙: 사용자 요청은 외부 API를 직접 호출하지 않고 **스케줄러가 갱신한 캐시**를 읽는다(`DEVELOPMENT_DIRECTION.md`).

## 1.4 AI 리포트 흐름 (스케줄 생성 → 저장 → 조회)

```mermaid
flowchart TB
    SCHED["APScheduler<br/>generate_daily_reports()"] --> GEN["AI 리포트 배치 생성"]
    GEN --> LG["LangGraph 파이프라인"]
    LG --> N1["financial / news / macro agent"]
    N1 --> N2["synthesizer (사실 통합)"]
    N2 --> N3["writer (리포트 작성)"]
    N3 --> N4["evaluator (품질 평가)"]
    N4 -->|미통과| N3
    N4 -->|통과 또는 한도 도달| SAVE["AIReport 테이블 저장"]
    USER["로그인 사용자<br/>GET /api/reports/{ticker}"] --> SAVE
    SAVE --> USER
```

> AGENTS.md 섹션 14 원칙: **사용자/챗봇 요청은 실시간 리포트 생성을 트리거하지 않는다.** 기본 동작은 DB에 저장된 스케줄 리포트 조회이다. (`POST /api/ai/generate/{ticker}` 엔드포인트는 존재하나 운영 정책상 일반 사용자 흐름의 기본 경로가 아니다.)
