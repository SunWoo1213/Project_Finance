## 6.3 로컬 실행 방법 (PowerShell, 저장소 루트)

### 1) 데이터베이스
```powershell
docker compose up -d db
```

### 2) 백엔드
```powershell
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
pytest        # 테스트
```

### 3) 프론트엔드
```powershell
cd frontend
npm install
npm run dev       # 개발 서버
npm run lint      # 린트
npm run build     # 프로덕션 빌드
```

## 6.4 환경 변수 (이름만, 값은 `.env`로 관리 — 커밋 금지)

| 변수명 | 용도 |
| --- | --- |
| `DATABASE_URL` | PostgreSQL 연결 (asyncpg) |
| `POSTGRES_USER` / `POSTGRES_PASSWORD` / `POSTGRES_DB` / `POSTGRES_PORT` | docker-compose DB |
| `SECRET_KEY` / `ACCESS_TOKEN_EXPIRE_MINUTES` | JWT 서명·만료 |
| `GOOGLE_CLIENT_ID` 계열 | Google 로그인 검증 |
| `OPENAI_API_KEY` | LLM 리포트 생성 |
| `FRED_API_KEY` / `ECOS_API_KEY` / `FINNHUB_*` / `STOOQ_API_KEY` 등 | 시장·매크로 데이터 |
| `MARKET_PRICES_REFRESH_MINUTES` / `MARKET_NEWS_REFRESH_MINUTES` | 캐시 갱신 주기 |
| `ENABLE_NOTIFICATION_SCHEDULER` / `NOTIFICATION_*` | 알림 스케줄러 |
| 리포트 생성/평가 환경변수 | AI 리포트 생성·평가 토글 |
| `BACKEND_CORS_ORIGIN_REGEX` 등 | CORS |

> 시크릿은 절대 코드/문서에 평문 기재하지 않는다(AGENTS.md 섹션 8). 위 표는 **변수명만** 표기.
